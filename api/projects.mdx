The Projects API lets you programmatically list and create documentation sites in your InkLoom account. A project is the top-level container for your pages, settings, and deployments — it maps directly to a hosted URL like `https://my-project.inkloom.dev`. Use these endpoints to automate site provisioning or keep project metadata in sync with your own systems.

---

## The project object

Every endpoint that returns a project uses the following shape.

<ResponseField name="id" type="string">
  Unique identifier for the project, prefixed with `proj_`. For example, `proj_abc123`.
</ResponseField>

<ResponseField name="name" type="string">
  Human-readable display name shown in the InkLoom dashboard.
</ResponseField>

<ResponseField name="slug" type="string">
  URL-safe identifier that determines your docs subdomain. For example, a slug of `my-docs` produces `https://my-docs.inkloom.dev`.
</ResponseField>

<ResponseField name="description" type="string | null">
  Optional description of the project. Returns `null` when not set.
</ResponseField>

<ResponseField name="visibility" type="string">
  Controls public access. One of `"public"` or `"private"`.
</ResponseField>

<ResponseField name="url" type="string">
  The fully-qualified live URL where your docs are hosted.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp recording when the project was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update to any project field.
</ResponseField>

## List projects

`GET /projects`

Retrieve a paginated list of all projects in your account. Results are ordered by `created_at` descending — most recent first.

```bash
curl https://api.inkloom.io/v1/projects \
  -H "Authorization: Bearer ik_live_xxxxxxxxxxxx"
```

### Response

```json
{
  "data": [
    {
      "id": "proj_abc123",
      "name": "My Docs",
      "slug": "my-docs",
      "description": "API documentation for My Product",
      "visibility": "public",
      "url": "https://my-docs.inkloom.dev",
      "created_at": "2025-01-15T10:00:00Z",
      "updated_at": "2025-06-01T14:22:00Z"
    }
  ],
  "next_cursor": null,
  "has_more": false
}
```

<ResponseField name="data" type="Project[]">
  Array of project objects for the current page.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Opaque cursor value. Pass this as the `cursor` query parameter to fetch the next page. Returns `null` when you have reached the last page.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` when additional pages of results exist beyond the current response.
</ResponseField>

<Tip>
  To paginate through all projects, keep requesting `GET /projects?cursor={next_cursor}` until `has_more` is `false`.
</Tip>

## Create a project

`POST /projects`

Create a new documentation project. The `slug` you choose must be unique across all InkLoom projects and becomes a permanent part of your docs URL — choose it carefully.

```bash
curl -X POST https://api.inkloom.io/v1/projects \
  -H "Authorization: Bearer ik_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"name": "My Docs", "slug": "my-docs", "visibility": "public"}'
```

### Request body

<ParamField body="name" type="string" required>
  Display name for the project. Shown in the dashboard and used as the default browser tab title.
</ParamField>

<ParamField body="slug" type="string" required>
  URL-safe identifier for the project subdomain. Must be lowercase, use only letters, numbers, and hyphens, and be globally unique. For example, `my-docs` → `https://my-docs.inkloom.dev`.
</ParamField>

<ParamField body="description" type="string">
  Optional short description of the project.
</ParamField>

<ParamField body="visibility" type="string" default="public">
  Access control for the hosted site. Pass `"public"` to allow anyone to view the docs, or `"private"` to restrict access to authenticated users. Defaults to `"public"`.
</ParamField>

### Response

Returns the newly created project object with HTTP `201 Created`.

<Note>
  InkLoom provisions a subdomain for your project immediately on creation, but the URL will return a 404 until you publish your first deployment.
</Note>
