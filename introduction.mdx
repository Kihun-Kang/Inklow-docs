InkLoom is an AI-powered documentation platform built for engineering teams who want accurate, up-to-date docs without the manual overhead. Point InkLoom at your codebase, and it generates comprehensive documentation automatically — then keeps it evergreen through a GitHub Action that syncs docs on every commit.

## How onboarding works

Get from a blank slate to live, AI-generated documentation in four steps.

<Steps>
  <Step title="Create a project">
    Run `npx create-inkloom@latest my-docs` to scaffold your documentation project locally, or create one directly from the InkLoom dashboard.
  </Step>
  <Step title="Connect GitHub">
    Link your repository in **Settings → GitHub Integration**. InkLoom installs the GitHub App and gains read access to your codebase.
  </Step>
  <Step title="Generate your docs">
    Click **Generate Docs** in the dashboard. InkLoom's AI scans your codebase and produces a full set of documentation pages — ready to edit and publish.
  </Step>
  <Step title="Deploy to the world">
    Hit **Deploy** in the dashboard or run `inkloom deploy <project-id> --production` from the CLI. Your docs go live on the edge in seconds.
  </Step>
</Steps>
